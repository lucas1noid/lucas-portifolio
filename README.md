## Tech

- React
- Vite
- JavaScript (ES6+)
- CSS (Flexbox, Grid)

## Run locally

1. Install dependencies

```bash
npm install
```

2. Start the development server

```bash
npm run dev
```

Open http://localhost:5173 (or the port shown) in your browser.

## Build

```bash
npm run build
```

The production-ready files are in the `dist` folder.

## Lint

```bash
npm run lint
```
